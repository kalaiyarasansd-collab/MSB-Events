# Team roadmap

Suggested work items; these are not implemented backend features.

- [ ] Connect Supabase authentication and remove plaintext local account storage.
- [ ] Create database tables for enquiries, blocked dates, packages, and profiles.
- [ ] Apply row-level security and server-enforced admin roles.
- [ ] Prevent duplicate confirmed bookings with database constraints and transactions.
- [ ] Connect calendar and admin actions to shared data.
- [ ] Review business content, contact details, accessibility, and mobile layouts.
- [ ] Add meaningful tests for booking transitions and date conflicts.
- [ ] Set production environment values and configure hosting after backend readiness.

Possible task split: one teammate handles UI and content, one handles the backend and access rules, and one handles calendar integration and validation. Agree on owners in GitHub issues before starting.
